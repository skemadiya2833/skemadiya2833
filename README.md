## 👨‍💻 About me

I'm Sunil, a software engineer and system architect based in Indore, India. I'm the founder of **[Devoids](https://devoids.in)**, a product-focused IT company where we design, build, and maintain software for startups, SMEs, and growing businesses, from the first idea all the way to production.

My background is in backend engineering, distributed systems, and full-stack product development. I've led teams building HRMS, ERP, and microservice-based platforms, and I like the kind of work where architecture is decided *before* the first line of code gets written.

I care about systems that are secure by default, fast, and easy for the next developer to pick up.
